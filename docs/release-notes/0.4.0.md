## 限制

- **真机项未验证**：VpnService 的实际报文转发、前台服务在锁屏/后台的存活、进程被杀与设备重启后的恢复、
  SAF 选择器的真机交互与真机上传下载均未在真实设备上执行；W16-02 因此仍未完成。控制面只承诺到
  "可点击、失败关闭、状态来自节点"。
- **深色模式未实现**：设计令牌在两种系统模式下都是同一套纸面配色，Android 刻意不发明第二套外观；
  这需要先在产品层面定义深色调色板，不是实现缺口。
- **macOS/Windows 未验证**：两台目标机的 release gate 未在本机执行；Linux 侧的 green 结论不能外推。
- **Secure Session v2 未接入生产数据面**：计划中的混合握手（X-Wing、Ed25519 + ML-DSA）尚未实现，
  发布阻断项以此为前提条件之一。
- **发布说明的"能力"节由 CHANGELOG 汇总**：它是变更清单，不替代逐平台的真机证据表。

## 迁移

无破坏性迁移。自 0.3.0 升级时：

- 节点连接设置不变（WebUI 地址与令牌仍在同一配置位置）；Android 首次启动新增引导页，未保存地址时不再显示故障面，
  已保存地址与令牌继续沿用本机 `SharedPreferences`。
- `#[ignore]` 测试现在必须带原因并引用真实存在的 runner；引用已删除脚本的写法会让 release gate 失败。
- `release-gate.py` 新增必选检查 `ignored-tests`；自行维护的等效脚本需要一并运行。
